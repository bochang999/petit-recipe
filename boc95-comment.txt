## 🔍 副作用分析完了 - 詳細技術レポート

### 📋 分析結果サマリー
**副作用の根本原因**: 3フェーズアーキテクチャ実装時の**ネイティブイベント管理配置問題**

---

### 🚨 特定された問題

**1. アーキテクチャ不整合**
- ネイティブリスナー(App.addListener)がアプリクラス外部で実装
- 外部リスナーが内部状態(app.history)に依存
- Phase 3(神経)とPhase 2(脳)の分離による責任の分散

**2. 具体的な問題箇所** script.js:691-701
```javascript
// 現在の問題構造
document.addEventListener("DOMContentLoaded", function () {
  app = new PetitRecipeApp();

  // 外部でネイティブリスナー設定 - これが問題
  App.addListener('backButton', () => {
    if (app.history.length > 1) {  // グローバル変数依存
      app.navigateBack();          // 外部からクラスメソッド呼び出し
    }
  });
});
```

**3. 影響範囲**
- コードの保守性・拡張性・デバッグ性低下
- リスナー重複登録のリスク
- アプリ再初期化時の孤立リスナー問題

---

### 💡 推奨解決策

**アプローチ**: ネイティブリスナーをアプリクラス内部に統合

```javascript
// 改善案
class PetitRecipeApp {
  setupEventListeners() {
    // 既存のDOMイベント管理...

    // ネイティブイベント統合
    this.setupNativeListeners();
  }

  setupNativeListeners() {
    if (typeof window.Capacitor !== "undefined") {
      App.addListener('backButton', () => {
        this.handleNativeBackButton();
      });
    }
  }

  handleNativeBackButton() {
    if (this.history.length > 1) {
      this.navigateBack();
    } else {
      App.exitApp();
    }
  }
}
```
